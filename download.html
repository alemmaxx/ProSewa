Cara pasangHow to install

  1. Kalau Chrome tunjuk amaran fail berbahaya, tekan Muat turun juga.
  2. Buka fail .apk dari notifikasi muat turun.
  3. Jika diminta, benarkan Pasang apl tidak diketahui untuk Chrome.
  4. Jika Play Protect bertanya, pilih Pasang juga.
  5. Buka app, kemudian tekan Benarkan untuk notifikasi. Di Tetapan, tekan 🧪 Uji notifikasi untuk pastikan ia berfungsi.
  6. Penyewa: tampal link daripada tuan rumah, atau tekan link itu dalam WhatsApp, app akan terus buka.
  1. If Chrome warns the file may be harmful, tap Download anyway.
  2. Open the .apk file from the download notification.
  3. If asked, allow Install unknown apps for Chrome.
  4. If Play Protect asks, choose Install anyway.
  5. Open the app, then tap Allow for notifications. In Settings, tap 🧪 Test notification to make sure it works.
  6. Tenants: paste the link from your landlord, or tap that link in WhatsApp and the app opens directly.

Pemasangan gagal?Install failed?

Jika keluar "App not installed", nyahpasang versi lama dahulu (sekali sahaja), kemudian pasang semula. Data anda selamat dalam sistem.If you see "App not installed", uninstall the old version first (one time only), then install again. Your data is safe in the system.
